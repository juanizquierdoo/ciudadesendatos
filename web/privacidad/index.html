Política de privacidad

Última actualización: 22/11/2026.

1. Qué datos recogemos

Esta web no tiene formularios, registro ni comentarios, y no usa cookies ni herramientas de analítica o publicidad. El titular no recoge datos personales de quienes la visitan.

2. Alojamiento de la web

La web se aloja en GitHub Pages, un servicio de GitHub, Inc. (Estados Unidos). Como ocurre con cualquier página, al visitarla tu navegador envía al servidor datos técnicos como la dirección IP, el tipo de navegador y la página solicitada. GitHub puede registrarlos para servir la web y por seguridad, según su declaración de privacidad. El titular no tiene acceso a esos registros.

La base jurídica es el interés legítimo en ofrecer la web de forma segura (artículo 6.1.f del RGPD). Los datos pueden tratarse en Estados Unidos; GitHub declara cumplir el Marco de Privacidad de Datos UE-EE. UU., que cuenta con una decisión de adecuación de la Comisión Europea.

3. Si nos escribes por correo electrónico

Si escribes a ciudadesendatos@gmail.com, usaremos tu dirección de correo, tu nombre si lo indicas y el contenido del mensaje solo para responderte. La base jurídica es tu consentimiento al escribirnos (artículo 6.1.a del RGPD). Conservaremos el mensaje mientras sea necesario para atender tu consulta y lo borraremos después, salvo que una ley obligue a guardarlo. No cedemos estos datos a nadie, salvo obligación legal; el proveedor del servicio de correo los trata por cuenta del titular.

4. Tus derechos

Puedes pedir el acceso, la rectificación o la supresión de tus datos, oponerte a su tratamiento, pedir su limitación o su portabilidad y retirar tu consentimiento en cualquier momento, escribiendo a ciudadesendatos@gmail.com. Si consideras que no se han respetado tus derechos, puedes presentar una reclamación ante la Agencia Española de Protección de Datos (www.aepd.es).

No se toman decisiones automatizadas ni se elaboran perfiles con tus datos.

5. Cambios en esta política

Si en el futuro la web incorpora analítica, publicidad o algún formulario, esta política se actualizará antes de activarlos y, cuando la ley lo exija, se pedirá tu consentimiento. Consulta también la política de cookies.

6. Responsable del tratamiento
